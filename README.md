# ScamSpotter

A quick-reference guide to common online scams, built for everyday
internet users and small business owners who want to recognise scam
messages and calls before they lose money.

## Stack
HTML, CSS, Bootstrap, JavaScript (no frameworks or plugins for the logic)

## Live site
https://chi-dan-ux.github.io/scamspotter/

## How to run
1. Clone this repo
2. Open index.html in your browser

## Features (Week 1)

### Search
The search box filters scams as you type. It ignores capital letters
and extra spaces, and checks the scam name, description and channel.
An empty search shows all scams, and a search with no matches shows a
helpful message.

### Channel filter
The chips (All, SMS, Email, WhatsApp, Phone Call) show only scams from
that channel. Search and filter work together.

## Accessibility
- Semantic HTML (header, nav, main, section, article, button, label)
- Labelled search field and visible focus outlines
- Skip link for keyboard users
- Text colours meet at least 4.5:1 contrast

## Design reference
The layout idea was generated with ChatGPT, then I built it myself.
